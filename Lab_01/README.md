# Lab 01 - Modern Simulation Tools: ModelSim and Logisim

## Objective

To get familiar with ModelSim and use them to design and simulate basic digital circuits.

## Tasks

1. Implement the 7 basic logic gates using Verilog gate-level modeling:
   - AND
   - OR
   - NOT
   - NAND
   - NOR
   - XOR
   - XNOR
2. Implement the same 7 basic logic gates using Verilog dataflow modeling.
3. Implement a 2-input XOR using basic gates with gate-level modeling.
4. Implement the XOR circuit using dataflow modeling and verify it.
5. Implement a 4-bit 1's complement circuit using gate-level modeling.
6. Implement the same 4-bit 1's complement circuit using dataflow modeling.
7. Simulate and verify the results using ModelSim testbenches.

## Concepts Covered

- Verilog
- Gate-level modeling
- Dataflow modeling
- Logic gates
- XOR implementation
- 1's complement
- Testbenches
- ModelSim
