# Lab 02 - Combinational Circuits

## Objective

To implement common combinational circuits using Verilog gate-level and dataflow modeling and verify their operation using testbenches.

## Tasks

1. Implement a Half Adder using gate-level and dataflow modeling.
2. Implement a Full Adder using gate-level and dataflow modeling.
3. Implement a 3-to-8 Decoder using gate-level and dataflow modeling.
4. Implement an 8-to-1 Multiplexer using gate-level and dataflow modeling.
5. Simulate the designs using Verilog testbenches.

## Concepts Covered

- Combinational circuits
- Half Adder
- Full Adder
- 3-to-8 Decoder
- 8-to-1 Multiplexer
- Gate-level modeling
- Dataflow modeling
- Testbenches
- ModelSim

The circuits were tested using Verilog testbenches in ModelSim and the required circuits were also created and verified in Logisim.
